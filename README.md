# BharatSpace

India-first real-time social network UI implemented from the final BharatSpace Figma mockup.

## Stack
- React
- Vite
- Plain CSS (no Tailwind)

## Implemented screens
- Onboarding / interests
- Home feed
- Discover
- Create post
- Activity
- Profile

## Design source
Figma: https://www.figma.com/design/9F9y0wHOAQ8Wu75x0LogE6/India-First-Social-App-%E2%80%94-Product-Mockup?node-id=0-1

## Run
```bash
npm install
npm run dev
```

## Notes
The implementation preserves the final Figma structure: 390px mobile layout, BharatSpace navy/orange palette, Instagram-like bottom navigation and social feed hierarchy. It uses CSS-built media artwork for the India Gate demo content because the Figma asset endpoint is temporary and was not reachable from the local runtime during export.
